# 📒 NotesKeeper - AsyncStorage

Aplikasi NotesKeeper dibuat menggunakan React Native Expo dan AsyncStorage.

## Fitur

### Level 1 (Core)
- ✅ Create catatan
- ✅ Read data dari AsyncStorage
- ✅ Update catatan
- ✅ Delete catatan
- ✅ Data tersimpan menggunakan AsyncStorage
- ✅ Empty State
- ✅ FlatList

### Level 2
- ✅ Update/Edit Catatan
- ✅ Konfirmasi Hapus

### Level 3 (Bonus)
- ✅ Timestamp pada setiap catatan

## Tech Stack

- React Native
- Expo
- AsyncStorage

## Cara Menjalankan

```bash
npm install
npx expo start
```

Scan QR Code menggunakan Expo Go.
